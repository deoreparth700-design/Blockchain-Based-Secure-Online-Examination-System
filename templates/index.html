How a result becomes tamper-evident

Dataname, answers, score
→
HashSHA-256 fingerprint
→
Blockindex + data + hash
→
Previous Hashlinks to prior block
→
Next Blockchain continues

Because each block's hash depends on the block before it, changing any old block's data changes its hash — breaking the chain of links to every block after it. Log in to see it for yourself on the View Blockchain page.

Who uses this system

Teachers log in with the account created for them, create exams with a start/end time window, and view results once students submit.

Students sign up with their name, roll number and a password, then log in to take any exam that is currently open.
